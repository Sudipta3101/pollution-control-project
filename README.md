# Pollution Controls Data Cleaning & Transformation

## Project Overview
This project focuses on cleaning, standardizing, transforming, and analyzing pollution monitoring data collected from various sources such as Continuous Emission Monitoring Systems (CEMS), ambient AQI sensors, laboratory reports, and inspection logs.

The objective is to improve data quality by handling inconsistencies, missing values, duplicate records, unit variations, and other data quality issues. The cleaned dataset is then transformed to generate meaningful insights for pollution monitoring and regulatory compliance.

---

## Objectives

- Clean and standardize raw pollution data.
- Perform data transformation for analytical purposes.
- Generate meaningful insights using data visualization.
- Implement all scenarios using Python and its libraries.
